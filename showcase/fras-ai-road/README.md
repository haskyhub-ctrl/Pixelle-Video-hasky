# FRAS-AI · Con đường an toàn

A 3D scroll journey in the style of robinpayot.com: the camera travels along a dotted road through
four pastel chapters (FRAS·AI, Nguy cơ, AI phân tích, An toàn). Waving cards with pin labels,
soft 3D toys (extinguisher, plug, flame, smoke detector, house, shield), chapter colours that shift,
and three modes: road, overview, list. Click a card for details.

`index.html` is self-contained (three.js, GSAP, Lenis, icons and photos inlined).

```
npm install
node build.mjs
```
